# HA-Games-Addon

Eine Sammlung klassischer Spiele als Home-Assistant-Add-ons.

## Installation

[![Repository zu Home Assistant hinzufügen](https://my.home-assistant.io/badges/supervisor_add_addon_repository.svg)](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2Ffvh02%2FHA-Games-Addon)

Oder manuell: **Einstellungen → Add-ons → Add-on Store → ⋮ → Repositories** und
`https://github.com/fvh02/HA-Games-Addon` hinzufügen.

## Spiele

| Add-on | Beschreibung |
| ------ | ------------ |
| [Stapeljagd](stapeljagd/DOCS.md) | Das Kartenspiel für 2–6 Spieler im Browser, auch mit Computer-Gegnern. |
